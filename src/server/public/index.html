Setup

nothing on this page contains a secret

1. Where the .env file goes

Create .env in the repository root — the same folder as package.json. Copy .env.example as a starting point: 

cp .env.example .env

.env is listed in .gitignore and must stay there. Never commit credentials, and never paste them into a browser field — this dashboard has no input for them and does not need one.

2. Environment variables

VariableSet?ValuePurpose

3. API key and secret

  1. Sign in at https://api.zebpay.com and open API Trading.
  2. Create a key. Scope it fetch:details for private reads and the private WebSocket.
  3. Add futures:trading as well if you want to place orders. A key doing full REST trading and private WebSocket events needs both scopes.
  4. Put the key in ZEBPAY_API_KEY and the secret in ZEBPAY_API_SECRET.
  5. Restart the dashboard. The secret is only ever used locally to sign requests — it is never sent and never displayed.

4. Subaccount

Leave ZEBPAY_SUBACCOUNT_ID empty to trade on the main account. Set it to the subaccount id to operate on that account; it is sent as the subaccountid header on REST calls and included in the signed WebSocket handshake.

5. API endpoints

Override only if ZebPay publishes a different host. The defaults above are the documented Futures endpoints.

6. Start the dashboard

7. Verify it

node bin/zepay.js doctor     # connectivity, clock skew, fees, safety
npm run check:live           # validate the real API shapes
